# Screenshots and listing assets

This repository currently lacks **privacy-reviewed, publisher-approved** store screenshots. Screenshots from local development contain third-party game artwork and may include account names, notification details and other personal information.

## Capture plan
- Portrait: original game with the compact companion bar, and expanded timer controls.
- Landscape: unobstructed game view with compact sidebar.
- Timer: local reminder countdown, and Android notification (without personal account details).
- Settings: alert sound settings and background permissions.

Before adding assets under `docs/screenshots/`, redact account names and other identifiers and secure rights to reproduce the game visuals. Keep screenshots truthful, not illustrative mockups represented as real app functionality.

For release, confirm current Play Console screenshot dimensions and format requirements.
