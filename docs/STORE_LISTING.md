# Draft Google Play listing (not approved)

**App name:** SEAF Companion (unofficial) — subject to trademark review

**Short description:** Unofficial Android companion with local mission reminders.

**Full description:** SEAF Companion provides a convenient Android view of the third-party SEAF website, a collapsible companion panel, and locally scheduled reminders. Timers are entered manually and are not synchronized to the SEAF game servers. This independently developed app is not affiliated with, endorsed by, or supported by the SEAF operators.

**Current limitations:** Internet access required for the game; mission status is not synchronized. Android can delay reminder delivery. Notifications depend on user permissions and settings.

**Do not publish before:** trademark/IP permission review, screenshot rights review, approved privacy-policy URL, Data Safety questionnaire, production signing and current target SDK compliance.
